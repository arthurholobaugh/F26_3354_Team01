# Team 1 - GlucoCare
### Glucose Monitoring System For Patients with Diabetes

## Prerequisites & Dependencies
- Java Development Kit (JDK) 17 or higher
- JUnit 5 (`junit-jupiter-api` and `junit-jupiter-engine`)
- Apache Maven (or a Java IDE with built-in JUnit 5 support such as IntelliJ IDEA, Eclipse, or VS Code)

## Environment Variables
- No external API keys or environment variables are required to compile or run the unit tests locally.
