# Team 1 - GlucoCare

## Prerequisites & Dependencies

### Git

1. Go to [https://git-scm.com/install/](https://git-scm.com/install/)

2. Select your operating system.

3. Follow all installation instructions.

### Visual Studio Code

1. Go to [https://code.visualstudio.com/download](https://code.visualstudio.com/download)

2. Select the correct installer for your system.

3. Open the installer and follow the installation instructions.

### Java Development Kit (JDK) 17 or higher

1. Go to [www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html](www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)

2. Under the section titled "Java SE Development Kit 17.0.12", select the correct installer for your system.

3. Open the installer and follow the installation instructions.

### JUnit Platform Console Standalone
1. Go to [https://mvnrepository.com/artifact/org.junit.platform/junit-platform-console-standalone/6.1.3](https://mvnrepository.com/artifact/org.junit.platform/junit-platform-console-standalone/6.1.3)

2. In the "Overview", click "jar".

3. Place the JAR file into the "lib" folder after cloning and opening the repository (see "How to Run Locally" section below).

### Extension Pack for Java

1. Open Visual Studio Code.

2. Select "Extensions" from the left sidebar or use the shortcut CTRL+SHIFT+X (Windows) / COMMAND+SHIFT+X (macOS).

3. Install "Extension Pack for Java" by "Microsoft".

## Environment Variables
No project-specific environment variables or API keys are required to compile or run the unit tests locally.

## How to Run Locally

1. Clone the repository using the following command in Command Prompt (Windows) or Terminal (macOS):
   ```shell
   git clone https://github.com/arthurholobaugh/F26_3354_Team01.git
   ```

2. Open the cloned project inside of Visual Studio Code.

3. Place the downloaded JAR file into the "lib" folder.

4. Select the SharingPermissionTest.java file.

5. Click the green arrow next to the class declaration to run all test cases.

6. Review results in the "Test Results" section of the Visual Studio Code terminal.
